# 相册帷幕：回忆长卷

## 范围

保留 `PhotoWall` 的照片来源、日期和署名、上传／换图／取下、分页与同步。只替换拉开帷幕后的密集照片墙；不更改云端照片、签到、历史留言、能量或已有素材。原上传缩略图的大图入口也保留。

## 视觉与分镜

- 点击拉绳后打开独立观看层；暖纸色背景，薄纸边、日期和署名。
- 左右帷幕用约 0.85 秒的位移动画展开；已加载照片淡入。开幕不等待整个相册下载，控制栏可以立即操作。
- 时间顺序不变，桌面采用单幅主景和双列交替的排版；手机单列。照片完整放入保留比例的展示区域，不做裁切或滤镜。
- 默认静止；“慢慢看”以约 27px/s 巡游，末尾停止。触摸、指针按下、滚轮、浏览键、原图预览或离开标签页均暂停；需要主动恢复。
- 月份选择跳到对应照片附近；关闭保存当前照片位置，重新打开恢复。调整窗口大小按照片锚点恢复，而非沿用旧像素位置。
- 原图支持上一张／下一张、适合屏幕和展开长图。Escape 先关闭原图，再关闭影展。

## 实现

- `src/album/AlbumTheater.jsx`：原生 dialog 与 Portal、背景隔离、焦点管理、观看及预览状态。
- `src/album/albumTheater.css`：独立作用域，不依赖旧相框的强制边框和溢出规则；手机安全区与减少动态效果。
- `src/album/galleryLayout.js`：稳定行几何及可见窗口；照片数量增加不会压缩卡片。仅当前视口和少量缓冲区挂载图片。
- `src/album/imageQueue.js`：每个影展实例最多 3 个加载任务，解码后显示；超时和错误释放队列；关闭清理任务与回调。只缓存少量图片尺寸信息。

当前版本使用已有图片 URL，没有生成缩略图、改写存储桶或下载私人图片到仓库。加载性能改善来自有限渲染、请求调度和后台暂停，不能代替真实网络传输速度。浏览器 HTTP 缓存继续负责图片资源复用。

## 验证与发布

运行 `node --test scripts/*.test.mjs` 和 `npm run check`。隔离测试覆盖 132 张照片的完整排序、不重叠的行几何、有限渲染、队列并发、错误与关闭清理。

本地浏览器使用仅存在于忽略目录／构建目录中的测试数据，包含横图、竖图和长图。检查开合、月份跳转、巡游暂停、原图展开、焦点恢复、观看位置恢复、390px 布局与控制台。测试页、测试图片和私人备份不进入部署。线上仅做只读验收，不用真实上传或删除操作测试。

不承诺所有设备恒定 60fps；原图尺寸、浏览器缓存、设备与网络都会影响解码和首图出现时间。
