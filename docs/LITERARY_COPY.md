# 展示文案与引用出处

本轮只调整公共界面的抒情展示文案，不改历史邀请信、用户留言及回复、照片说明、已发布任务、签到、道具及能量数据。加载、上传、删除、播放、签到等操作说明不改成诗句，避免影响可用性。

## 维护方式

引用集中在 `src/data/literaryQuotes.js`。`provenance` 区分用户提供但无可靠署名的文字、已核对节选与公版作品；未核实的引用不显示作者或书名。

`LiteraryQuote` 使用 blockquote / cite 语义，作者与篇名链接到核对依据。来源页不会被预加载，不增加页面初始外部请求。原文采用简体字与适合屏幕的标点／分行，不声称这些排版是原书版式。

相册开头保留独立的隐藏标题用于对话框可访问名称；两段引用不影响月份跳转、图片比例、加载队列或巡游逻辑。
