# 每日签到簿 · 日有所进

## 已确定的设计

- 暖纸精装书；电脑宽度大于 760px 时小琛左页、小琳右页，手机默认小琳单页，可用书签切换。
- 日期对应一组对页。前后按钮、日期选择器和非输入区域的左右方向键可导航；过去日期使用“补卡”。本篇章从 2026-10-14 开始，旧 300–365 天保持独立。
- 昨夜睡眠：可选入睡时间、可选截图，按醒来的日期归页；23:40 默认归前夜，00:30 默认归当天，可手动调整。
- 今日手记：逐条记事，可文字、图片或图文组合，支持编辑、顺序调整、移除与会话内撤销。旧 activities 原文作为第一条显示，不覆盖原始字段。自习时长仍是全天汇总且可选。
- 所有字段可以留空后签到。签到后仍可补充，保存不会取消签到。新的签到不产生旧抽奖机会。
- 周目标默认每周 5 晚在 00:00 之前入睡。周一至周日统计，缺少睡眠记录不算达标，也不算失败；00:00 恰好不属于“之前”。
- 目标设置为当前周并立即重算本周达标情况，不改睡眠记录。过去周不允许修改，仍按当时目标读取。此前已安排的未来目标保留。

## 静态构图与翻页

封皮、静态页边和书脊渐变表现厚度；页面内部按细线分隔，不堆叠卡片。翻页使用 520ms 的 transform/opacity 动画，260ms 时切换下层日期，只渲染一张临时翻页。翻页期间禁止编辑和重复导航。

prefers-reduced-motion 时直接切页；手机保留可触摸的前后按钮，输入区域不触发左右翻页。内容超过默认纸页高度时自然增高，不缩小字体或截断记录。

## 文件与数据

- `src/main.jsx` 只增加按需加载入口，旧内容保留在“内容小册”和“那 65 天”。
- `src/journal/GrowthJournal.jsx` 管理书页、草稿、目标、截图预览和冲突对照。
- `journalModel.js` 提供上海日期、周归属、午夜判断和输入校验。
- `journalStore.js` 使用独立 IndexedDB 保存草稿；本地模式保存测试记录。线上仅通过 API 保存，离线不伪报成功。
- `api/journal.js` 验证已有站点 Cookie，使用服务端 service role。每人每天一行，按 version 比较后更新，冲突返回 409 和已保存内容；无覆盖重试。
- `supabase_wwcxrl_journal.sql` 由用户手动执行。新增两个启用 RLS 的表和私有截图桶，无匿名权限，不改旧签到、相册、奖品和积分。

姓名是此双人网站内的记录署名，不是独立登录账户；通过共享站点密码的人可切换编辑两页。两个人分行保存，避免互相覆盖。

截图经浏览器压缩去除 EXIF，最长边 2400px，预览使用同一张已压缩图片。存入私有 `wwcxrl-journal` 桶，阅读时签发 1 小时 URL；不加入生活相册。替换或移除截图只变更当前记录的引用，不自动删除云端文件。

## 验收与上线

运行 `npm run check` 和 `node --test scripts/*.test.mjs`。隔离浏览器验证双页/单页、空白签到、补卡、跨午夜统计、草稿恢复、截图上传放大、当前周目标即时生效及双页面编辑冲突。测试使用忽略目录中生成的图片和本地测试日期，不接触生产数据。

先确认新增 SQL 执行成功，再合并并部署到 main。数据表未就绪时，线上接口会显示同步失败且保留本机草稿。


## 今日手记与紧凑睡眠区

睡眠常态约 100–120px，高度不再占用半页；修改时才展开时间控件，七日进度移入目标面板。截图以邮票大小显示，无截图时只留上传入口。

手记结构保存在现有 content JSON 中，无数据库迁移。附图使用同一个私有桶，逐张生成高清压缩图和 640px 缩略图，浏览只加载缩略图；点开再下载高清图。多图组横向滚动，手机缩略图最高 110px、单图最高 150px，不裁切。睡眠截图不混入手记。

保存继续检查 version。旧客户端若不认识 notes 字段，服务端拒绝其覆盖已升级的手记，要求刷新。签名 URL 刷新只合并媒体地址，不覆盖正在编辑的文字、顺序或待上传图片。删除条目/附图仅修改引用，不删除存储文件；撤销恢复指定项，不回滚其他编辑。


空白条目不显示为“还没写内容”，重新书写会复用空草稿，不改已有存储记录。一次仅展示一个编辑器，完成空白输入后回到单一书写入口。手机移除手记区固定最小高度，编辑按钮缩为可键盘访问的图标。入睡时间旁显示明确月日，避免“前夜”歧义；原有时间及日期归属不自动更改。


目标浮层使用固定两列控件与七等分周进度，限制在视口内。图文条目阅读时文字左、图片右；编辑或纯图片条目保持完整宽度。独立“今天的一点进步”为可选 500 字字段，保存在既有 content.growthNote 中，随草稿、签到、补卡和冲突处理一起保存；旧客户端缺失此字段时不可覆盖已写内容，无需新增 SQL。


手记采用连续段落留白，不再显示底部“记一件事”块或条目隔线；从标题旁“续写”另起一段，原有多条记录不合并、不删除。图文间距压为 6px，编辑图标跟随文字末尾，不独占一列。进步留言默认单行，随内容增高至两行，超过时框内滚动，不截断已保存文字。
