# 每日签到簿 · 日有所进

## 已确定的设计

- 暖纸精装书；电脑宽度大于 760px 时小琛左页、小琳右页，手机默认小琳单页，可用书签切换。
- 日期对应一组对页。前后按钮、日期选择器和非输入区域的左右方向键可导航；过去日期使用“补卡”。本篇章从 2026-10-14 开始，旧 300–365 天保持独立。
- 昨夜睡眠：可选入睡时间、可选截图；每页固定记录前一晚，例如 16 日书页记录 15 日夜间，23:40 与跨午夜的 00:30 均归该晚，取消日期选择。
- 今日手记：每人每天只显示一个文字框，直接增删文字并用“·”分点。旧文字按顺序显示，编辑时合并为一个内容块，全部照片仍保留；自习时长仍是全天汇总且可选。
- 统一使用“保存记录”，所有字段可选、过去日期可补录；文字、照片、睡眠一起同步，不再区分保存与签到。旧 checkedIn 字段仅兼容保留，不用于限制阅读。
- 周目标默认每周 5 晚在 00:00 之前入睡。周一至周日统计，缺少睡眠记录不算达标，也不算失败；00:00 恰好不属于“之前”。
- 目标设置为当前周并立即重算本周达标情况，不改睡眠记录。过去周不允许修改，仍按当时目标读取。此前已安排的未来目标保留。

## 静态构图与翻页

封皮、静态页边和书脊渐变表现厚度；页面内部按细线分隔，不堆叠卡片。翻页使用 520ms 的 transform/opacity 动画，260ms 时切换下层日期，只渲染一张临时翻页。翻页期间禁止编辑和重复导航。

prefers-reduced-motion 时直接切页；手机保留可触摸的前后按钮，输入区域不触发左右翻页。内容超过默认纸页高度时自然增高，不缩小字体或截断记录。

## 文件与数据

- `src/main.jsx` 只增加按需加载入口，旧内容保留在“内容小册”和“来时的我们”。
- `src/journal/GrowthJournal.jsx` 管理书页、草稿、目标、截图预览和冲突对照。
- `journalModel.js` 提供上海日期、周归属、午夜判断和输入校验。
- `journalStore.js` 使用独立 IndexedDB 保存草稿；本地模式保存测试记录。线上仅通过 API 保存，离线不伪报成功。
- `api/journal.js` 验证已有站点 Cookie，使用服务端 service role。每人每天一行，按 version 比较后更新，冲突返回 409 和已保存内容；无覆盖重试。
- `supabase_wwcxrl_journal.sql` 由用户手动执行。新增两个启用 RLS 的表和私有截图桶，无匿名权限，不改旧签到、相册、奖品和积分。

姓名是此双人网站内的记录署名，不是独立登录账户；通过共享站点密码的人可切换编辑两页。两个人分行保存，避免互相覆盖。

截图经浏览器压缩去除 EXIF，最长边 2400px，预览使用同一张已压缩图片。存入私有 `wwcxrl-journal` 桶，阅读时签发 1 小时 URL；不加入生活相册。替换或移除截图只变更当前记录的引用，不自动删除云端文件。

## 验收与上线

运行 `npm run check` 和 `node --test scripts/*.test.mjs`。隔离浏览器验证双页/单页、空白签到、补卡、跨午夜统计、草稿恢复、截图上传放大、当前周目标即时生效及双页面编辑冲突。测试使用忽略目录中生成的图片和本地测试日期，不接触生产数据。

先确认新增 SQL 执行成功，再合并并部署到 main。数据表未就绪时，线上接口会显示同步失败且保留本机草稿。


## 今日手记与紧凑睡眠区

睡眠常态约 100–120px，高度不再占用半页；修改时才展开时间控件，七日进度移入目标面板。截图以邮票大小显示，无截图时只留上传入口。

手记结构保存在现有 content JSON 中，无数据库迁移。附图使用同一个私有桶，逐张生成高清压缩图和 640px 缩略图，浏览只加载缩略图；点开再下载高清图。多图组横向滚动，手机缩略图最高 110px、单图最高 150px，不裁切。睡眠截图不混入手记。

保存继续检查 version。旧客户端若不认识 notes 字段，服务端拒绝其覆盖已升级的手记，要求刷新。签名 URL 刷新只合并媒体地址，不覆盖正在编辑的文字、顺序或待上传图片。删除条目/附图仅修改引用，不删除存储文件；撤销恢复指定项，不回滚其他编辑。


空白条目不显示为“还没写内容”，重新书写会复用空草稿，不改已有存储记录。一次仅展示一个编辑器，完成空白输入后回到单一书写入口。手机移除手记区固定最小高度，编辑按钮缩为可键盘访问的图标。入睡时间旁显示明确月日，避免“前夜”歧义；原有时间及日期归属不自动更改。


目标浮层使用固定两列控件与七等分周进度，限制在视口内。图文条目阅读时文字左、图片右；编辑或纯图片条目保持完整宽度。独立“今天的一点进步”为可选 500 字字段，保存在既有 content.growthNote 中，随草稿、签到、补卡和冲突处理一起保存；旧客户端缺失此字段时不可覆盖已写内容，无需新增 SQL。


手记采用连续段落留白，不再显示底部“记一件事”块或条目隔线；从标题旁“续写”另起一段，原有多条记录不合并、不删除。图文间距压为 6px，编辑图标跟随文字末尾，不独占一列。进步留言默认单行，随内容增高至两行，超过时框内滚动，不截断已保存文字。


今日手记只保留一个常驻文字框，取消续写、逐条编辑和排序操作。旧文字按顺序连接，编辑时合为一条，图片保持原顺序；删除文字不删除照片。“· 分点”格式化当前行，分点行回车接续下一点，Shift+Enter 普通换行，中文输入法组词期间不处理回车。进步留言保持独立。


睡眠目标展开面板中的七日状态：已记录且达到入睡目标为绿色，已记录但未达标为红色，没有睡眠记录为中性。无需截图或签到才能判定；保存时间、补卡或修改当前周目标后重算。周标记固定归书页日期的前一晚，忽略旧版 sleepPreviousDay 选择值但不重写存储记录；时刻按夜间顺序（晚间→午夜→凌晨）比较，等于目标不算“之前”。日期归属不参与时刻大小判断，不改写历史时间。周数据额外读取下周一的书页，避免漏算补录的周日睡眠。

编辑显示“有修改待保存”，统一按钮为“保存记录”，成功后显示“已同步”；本地测试模式显示“已保存”。本机草稿明确提示保存后才同步，发现其版本落后于云端时主动显示冲突对照；切换日期与手动刷新均重新读取云端。睡眠截图加载失败可单独重试，刷新媒体不覆盖本机草稿。目标面板支持点击外部收起，Esc 收起并将焦点返回展开入口。

草稿恢复会先等当前日期的云端读取完成；自动跳过与云端相同、相对保存基线没有改动，以及从未保存过的空白草稿。已有记录被清空属于真实修改，不自动丢弃；未上传图片也保留。载入云端版本会先清理本机草稿，再进入干净状态，无需再保存，清理失败则保留两份内容并允许重试。

跨设备读取优先展示较新云端正文：恢复时发现真实草稿版本落后，会在 IndexedDB 的 recovery 仓库事务性备份后移出活动草稿，正文展示云端图文；备份可折叠查看并主动恢复，尚未上传的图片字节保留。正在编辑时遇到新版本仍保留输入并提示冲突；选择云端会先备份当前草稿。保存清理仅删除与本次提交内容及版本相同的草稿，避免误删另一标签新写的内容。读取结果按版本合并，迟到的旧响应不能回退已保存内容。切换署名和页面恢复可见时重新读取。

本机数据库升级至版本 2，仅新增 recovery 仓库，旧 entries/drafts/goals 不清空；无需 Supabase SQL。跨设备行为通过服务端版本与签名照片读取测试，以及隔离本地数据的两个页面交错保存、刷新、翻页、旧草稿恢复和图片保留流程验收；不写入正式记录。

## 奶油贴纸签到簿（本地视觉预览）

沿用电脑双页、手机单页和现有日期 / 保存流程，仅在 `GrowthJournal.css` 中以 `.journal-cream` 限定视觉覆盖；不修改全站按钮规则。书页采用奶油纸色、柔和页边阴影，姓名用柚子黄 / 蜜桃粉书签区分，日期控件与保存按钮保留清楚的触摸区域。手记输入框与进步区域增加浅色边界；不会改变记录结构、照片排列、睡眠归属、草稿恢复或冲突处理。

`GrowthJournal.jsx` 仅增加样式类、装饰图标与根据已有 dirty / version 状态显示的小勾。小勾出现时播放一次 360ms 缩放动画，按钮提供悬停和按压反馈；减少动态效果模式取消动画和位移。翻页动画与所有事件处理保持原样。已保存状态也会在重新载入记录时显示，不另造“同步成功”状态。

本地验证：日记回归 25 项通过；浏览器验证文字编辑、保存、前后翻页返回、手机署名切换、目标展开 / Esc 关闭；320px / 390px 单页未发现横向溢出，主页面控制台无错误。手机 iframe 预览壳捕获到 MutationObserver.observe 的 Node 类型报错；业务源码和预览壳源码均无该调用，来源未确认，未影响上述操作验证。验证使用禁用 Supabase 配置的本地独立端口和示例文字，未写入线上数据库。生产构建通过；`npm run check` 的依赖审计仍被现有 Vite 6.4.3 高危漏洞阻断，本次未升级依赖。视觉预览尚未提交或部署。

## 图文手账：整幅文字 + 今日碎片

手记改为单列纵向阅读：整幅文字在前，「今日碎片」照片区在后。文字框随内容自然增高，取消 240px 上限和内部滚动；不增加阅读 / 编辑切换，不改变分点输入、中文输入法和保存方式。

单张照片使用一列宽相框，多张照片按原顺序两列换行；横竖图片均在固定相框中完整缩放，不裁切、不横向滚动。轻薄白边、静态纸胶带和局部阴影营造贴照片的手账感，图片数量与添加入口位于同一工具栏。移除按钮保持可见、44px 点击高度，撤销、高清预览、前后翻图与键盘关闭沿用原逻辑。手机继续两列小相框，可点开查看完整大图；无照片时只显示简洁的添加入口。

修改范围为 `JournalNotes.jsx` 与 `growthJournal.css` 的局部规则。既有 notes JSON、图片 ID / 顺序、原文件、缩略图签名和版本冲突机制保持不变；无需数据库迁移。测试插画是 `.cache/` 中的原创几何图，只用于本地横图 / 竖图 / 方图排版，不提交或上传到生产。

图文改版验收：日记回归 25 项通过；本地浏览器验证 18 行长文自然展开、横图 / 长竖图 / 方图、多图换行、单图与无图切换、放大 / 翻图 / Esc、移除与连续撤销、图文保存后刷新保留。320px / 390px 手机单页已检查。主页面控制台无错误；预览均禁用云端连接。`npm run check` 构建通过，依赖审计仍受此前 Vite 高危漏洞阻断，未提交或部署。

## 周一跨周睡眠补录

睡眠周改由 `sleepWeekStart(书页日期)` 计算，即先取书页前一晚，再确定周一至周日。周一书页显示并统计上周日夜间；本地 `loadWeek` 与 API GET 使用相同范围（该睡眠周周一至次周一的书页）。API 的目标查询仍截止书页所在周，保留上周适用目标与本周目标，避免周一设置新目标污染上周统计。

界面始终显示完整夜间日期、星期与所属周；过去书页标题为「睡眠记录」。历史周详情不再隐藏，七日按钮可以进入对应的次日书页补录；尚未到来的书页和记录起点前日期不可点击。统计只计算已保存时间，未记录保持中性。历史目标只读；周一详情中单独标明「设置新一周目标」，更新仅作用于本周。手机详情改为页内展开，避免目标控件挂在屏幕下方；Esc 关闭及保存目标后均将焦点返回入口。

时间填写的「完成」更名为「收起填写」，提示凌晨仍属于该夜、需点击页底「保存记录」。只调整显示/读取逻辑，不更改既有日期、睡眠时间或数据库结构。感受字段的校验错误也改用「感受记录」，保持与界面文案一致。

验证：28 项日记测试通过，包含周一新加载、周日保存、前后端读取范围一致、跨月跨年、历史目标保护。独立本地端口将日记时钟固定为 2026-10-19 周一，验证周日晚 23:30 保存为上周 1/5、修改本周目标仍保持上周结果、点周六进入周日书页、刷新恢复及 320px 手机详情；不读取或写入线上数据库。部署时需同步更新前端和 `api/journal.js`，无需执行 SQL。
